1. WHAT IS THIS PROJECT?
--------------------------------------------------------------------------------

This is a Library Management System. It is a web application that helps a 
college or library to:
  - Store and display books
  - Register students
  - Issue books to students
  - Record when students return books
  - See which books are in stock or out of stock

Teachers can think of it as a small software that replaces a paper register 
for issuing and returning books. Everything is stored in a database and 
shown on a website.


--------------------------------------------------------------------------------
2. ALL FUNCTIONALITY (WHAT THE SYSTEM CAN DO)
--------------------------------------------------------------------------------

A. BOOKS PAGE (HOME)
   - Shows all books in a grid (like an online store).
   - Each book shows: cover image, title, author, class (semester), and whether it 
     is "In Stock" or "Out of Stock".
   - Search: User can search by book title or author name.
   - Filters: User can filter by Class (FY/SY/TY/MCS semesters) and by 
     Availability (In Stock / Out of Stock).
   - Pagination: If there are many books, they are shown page by page 
     (e.g. 12 books per page) with Previous/Next buttons.
   - Total count: The page shows total number of books in the library.

B. ADD BOOK
   - Librarian or admin can add a new book.
   - Form asks for: Title, Author, Class (semester), Quantity (how many copies), and 
     optional Cover Image URL.
   - After submitting, the book appears in the Books list.

C. RESTOCK (UPDATE QUANTITY)
   - For each book there is a "Restock" button.
   - Used to change the number of copies (quantity).
   - If quantity is 0, the book shows "Out of Stock". If quantity is 1 or 
     more, it shows "In Stock".
   - So we can move a book from out of stock to in stock by increasing 
     the quantity.

D. REMOVE BOOK
   - Each book has a "Remove" button.
   - Used to delete a book from the library permanently (after confirmation).

E. STUDENTS PAGE
   - Shows a list of all registered students.
   - Displays: Student ID, Name, Class, and Email.

F. ADD STUDENT
   - Used to register a new student in the system.
   - Form asks for: Name, Class (e.g. BCS-2), and Email.
   - After submitting, the student appears in the Students list.

G. ISSUE BOOK (Issue/Return Page)
   - User selects a book (from dropdown of in-stock books) and a student.
   - On "Issue", the system:
     - Records that this book is issued to this student (with today's date).
     - Reduces the book quantity by 1. If quantity becomes 0, the book 
       becomes "Out of Stock".

H. RETURN BOOK (Issue/Return Page)
   - Recent issue records are shown on the same page.
   - For each issued book that is not yet returned, there is a "Return" 
     button.
   - On "Return", the system:
     - Marks the return date (today).
     - Increases the book quantity by 1 so the book is back in stock.

I. NAVIGATION & LAYOUT
   - Top navigation bar: Home, Books, Students, Issue/Return, Add Book, 
     Add Student.
   - On small screens (mobile), the menu becomes a hamburger icon.
   - Footer shows project context (BCS second year, college name) and 
     credits (developer, guide).


--------------------------------------------------------------------------------
3. TECHNOLOGY USED (SIMPLE TERMS)
--------------------------------------------------------------------------------

- Frontend: HTML (structure), CSS (styling). The website is responsive 
  (works on mobile and desktop).

- Backend: Python with Flask framework. Flask handles all the routes 
  (URLs) and talks to the database.

- Database: MySQL. We have three main tables:
  - books (book details and quantity)
  - students (student details)
  - issue_return (records of who took which book and when they returned it)

- So: User opens the website -> Flask runs on the server -> Flask reads 
  or writes data in MySQL -> Result is shown on the webpage.

4. HOW TO EXPLAIN IN SHORT (FOR ORAL PRESENTATION)
--------------------------------------------------------------------------------

"You can say something like:

  'This is a Library Management System. It has a Books page where we can 
   see all books, search and filter them, and see if they are in stock or 
   out of stock. We can add new books and remove old ones. We can also 
   restock a book to change its quantity.

   There is a Students page where we register students with name, class, 
   and email. On the Issue/Return page we issue a book to a student; the 
   system reduces the book quantity. When the student returns the book, 
   we click Return and the quantity increases again. All this is built 
   with Python Flask and MySQL, and the frontend is responsive HTML and 
   CSS.'"
