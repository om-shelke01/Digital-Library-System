Project Title:
  Academic Digital Library System (Flask + MySQL)

Objective:
  To build a simple web-based Library Management System for an academic
  environment that can:
    - Store and display books
    - Register students
    - Issue books and record returns
    - Track available stock (quantity)

Technologies Used:
  - Frontend: HTML5, CSS3 (Responsive UI using Grid and Flexbox)
  - Backend: Python (Flask)
  - Database: MySQL

Main Features:
  1) Books Page (Home)
     - Displays books in a responsive grid (cover, title, author, class/semester)
     - Shows availability (In Stock / Out of Stock)
     - Search by title/author
     - Filter by class/semester and availability
     - Pagination for large data
     - Total books count shown on top
     - Actions:
         - Restock / Update quantity
         - Remove book

  2) Add Book
     - Form to add a book (title, author, class/semester, quantity, optional cover URL)

  3) Students
     - Displays registered students (ID, name, class, email)
     - Add Student form (name, class, email)

  4) Issue / Return
     - Issue a book to a student (dropdown selection)
     - Automatically reduces book quantity on issue
     - Return a book using the Return button
     - Automatically increases book quantity on return
     - Shows recent issue/return records

How the Project Works (Step-by-step):
  1) User opens the application in the browser.
  2) Browser sends a request to Flask (app.py routes).
  3) Flask calls database functions (database.py) to fetch or update data.
  4) MySQL returns the data to Flask.
  5) Flask renders an HTML template (templates/) and sends the page back.
  6) User performs actions:
     - Add Book / Add Student: data is inserted into MySQL
     - Issue Book: a record is inserted into issue_return, and quantity decreases
     - Return Book: return_date is set and quantity increases
     - Restock: quantity is updated
     - Remove: book is deleted (and related records are removed via CASCADE)

Future Enhancements (Suggestions):

  - Role-based access (student view vs admin actions)
  - Better search (multi-field + sorting)

  - Book categories with better normalization (separate genre table)
  - Input validation improvements and better error handling
  - Use environment variables for secrets and remove hard-coded credentials
  - Deploy to a server (Gunicorn + Nginx) instead of Flask debug mode
